# 🎮 Mundo de Estudos - Quiz Retrô

Um jogo interativo de perguntas e respostas criado para transformar a revisão escolar do 4º ano em uma experiência divertida e engajadora, inspirada em videogames clássicos de 16 bits.

## ✨ Funcionalidades (Atualizadas)

* **Sistema Multi-jogador e Nuvem:** Utiliza o Supabase (PostgreSQL) para gravar recordes individuais e progresso de usuários separadamente, exigindo login.
* **Placar Geral (Leaderboard):** Compare seus recordes com os amigos! Uma tela secreta (código: Y, X, B, A) exibe o Hall da Fama.
* **Sistema de Combos e Maestria:** Acertar de primeira garante mais pontos e salva a questão como "dominada", incentivando o jogador a completar a matéria inteira (ex: 15/15).
* **Reset de Progresso Específico:** Para recomeçar os estudos, jogadores podem zerar sua nota em uma matéria específica pressionando a sequência secreta de botões (A, B, X, Y) em cima do teste desejado.
* **Suporte Completo a Gamepads (Xbox e PlayStation):** Símbolos dinâmicos na tela representam perfeitamente controles nativos de Microsoft (A, B, X, Y) e Sony (✖, ⭕, 🟦, 🔺).

## 🕹️ Como Jogar

O jogo foca em tempo de resposta e retenção. Se a tela ficar inativa por 15 segundos, ela recua para focar na arte ambiente.

**No Controle (Gamepad):**
* **Navegar:** Direcional D-Pad ou Botões de Ombro (L1/R1).
* **Entrar:** Botão `A` ou `✖`.
* **Segredos:** Menu Reset (`A, B, X, Y`), Leaderboard (`Y, X, B, A`).

**No Teclado:**
* **Navegar:** Setas direcionais.
* **Entrar:** `Enter`.
* **Opções (1 a 4):**
  * `1` = A / ✖
  * `2` = B / ⭕
  * `3` = X / 🟦
  * `4` = Y / 🔺
